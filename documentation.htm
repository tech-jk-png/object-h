Endpoints (`/object-h/api/v1`)

GET /resources

Returns a list of all supported models and system status.

GET /localhost

Healthcheck route confirming active local runtime environment details.

POST /chat/completions

Generates chat completions for text models.

Example Request Body: 
{
  "model": "gemini/3-6_flash",
  "messages": [
    { "role": "user", "content": "Hello world!" }
  ]
}

POST /images/generations

Generates image assets using Nano Banana 2.

Example Request Body: 
{
  "model": "google/nano-banana-2",
  "prompt": "Futuristic neon city",
  "n": 1
}

POST /video/generations/

Initiates video generation task using Jimeng Seedance 2.0 Fast.

Example Request Body: 
{
  "model": "bytedance/doubao-seedance-2-0-fast-260128",
  "prompt": "Ocean waves at sunrise",
  "duration": 5
}
